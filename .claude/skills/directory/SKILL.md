# directory

Read `product-marketing` first.

## Why bother

Directory listings are slow, unglamorous, and cumulative: durable backlinks
(`seo-audit`), entity corroboration for LLM retrieval (`ai-seo`), and a
trickle of high-intent traffic. A weekend of submissions keeps producing for
years.

## Where to list, ranked

1. **TradingView script library** — the most important listing we have; see
   `aso`. Not optional.
2. **Telegram channel directories** — tgstat, telemetr, and niche channel
   lists. Free, index the public channel.
3. **Trading tool aggregators and review sites** — indicator roundups,
   "best NQ tools" lists. Many accept submissions; some take payment, which
   is usually not worth it at our margins.
4. **Prop-firm resource pages** — communities often maintain tool lists.
   Approach via `co-marketing`, not a cold form.
5. **Product directories** (Product Hunt-class) — poor fit. Their audience is
   builders, not futures traders. Skip unless launching a `free-tools` item,
   where a developer audience is actually relevant.
6. **GitHub** — the repo itself, if any part is ever open-sourced. A public
   webhook-payload validator would attract exactly the technical buyer we
   want.

## Listing hygiene

Consistency is the point. Every listing carries the same name, the same
one-line description, the same URL, and the same logo (`ai-seo` entity rules).

Standard one-liner:
> Session-gated SMC signals for NQ/MNQ — liquidity sweeps and VWAP
> mean-reversion, delivered as complete trades to TradingView and Telegram.

Under 25 words, mechanism-first, no claims.

## Rules

- Claim the listing where possible so it can be updated.
- Never pay for a listing on a site that will not show its traffic.
- Do not submit to link farms or "SEO directory" packages. They are a
  liability, not a backlink.
- Every listing gets a unique UTM (`analytics`) so dead directories can be
  identified and dropped.
- Recheck listings quarterly; stale prices are a compliance problem
  (`pricing`).
